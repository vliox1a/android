# android

安卓 / 手机相关的 Windows 工具合集。**每个软件一个子文件夹**，互不混放。

| 目录 | 说明 |
|------|------|
| [DevAssist](./DevAssist/) | 组件清理：USB 调试扫描并停用预置采集组件 |

## 下载

- 推荐：各工具目录内的说明 + [Releases](../../releases)
- 下个新软件：在本仓库新建文件夹（例如 `SomeTool/`），把 exe 和说明放进去再提交

## 结构示例

```
android/
  README.md          ← 本索引
  DevAssist/
    DevAssist.exe
    README.md
  下一个软件/
    ...
```
