# DevAssist · 组件清理

> Windows 桌面工具：通过 USB 调试，扫描并停用 / 卸载安卓机里的常见预置组件。  
> **单文件分发** · ADB 已内置 · 无需安装

## 功能

- 按厂商浏览常见预置 / 采集类组件（小米、一加、OPPO、vivo、华为、荣耀等）
- 扫描本机：已装 / 运行中 / 已停用
- 停用 / 卸载 / 冻结(suspend)；失败时自动切换多种 ADB 命令
- 操作日志；支持恢复所选组件

---

## 使用前准备

1. 电脑：Windows 10 / 11  
2. 手机：用数据线连接电脑  
3. 打开 **开发人员选项**（设置 → 关于手机 → 连点版本号）  
4. 开启 **USB 调试**，手机上允许本机调试  
5. 华为 / 荣耀 / 部分 vivo：若有 **USB 调试（安全设置）**，一并打开  

---

## 使用步骤

1. 双击 `DevAssist.exe`  
2. **刷新设备** → **扫描本机**  
3. 勾选组件 → **按推荐停用** 或卸载  
4. 需要时用 **恢复所选**

---

## 机型说明

| 情况 | 说明 |
|------|------|
| 一加 / OPPO / realme / 小米 等 | 普通 USB 调试下，多数组件可用本工具处理 |
| 华为 / 荣耀 / 部分 vivo·iQOO | 系统常拦截 ADB（如 `no root permission`、`DELETE_FAILED`）。本工具会尝试停用、卸载、冻结，**仍可能失败** |
| Shizuku | 通过 ADB 启动时权限≈普通 shell，**不能保证**比本工具更能成功；受保护包有时仍需 root |
| 显示「未安装」 | 该机没有名单里的包，属正常 |

扫描各品牌都可以试；**能否停用取决于机型策略，不保证全品牌都能清掉。**

---

## 注意事项

- 新机 / 刚换卡时，部分登记类组件勿动  
- 「卸载」比「停用」更彻底，恢复也更麻烦  
- 不建议更新系统  
- 删除本软件：删除 `DevAssist.exe` 即可；日志目录 `%LOCALAPPDATA%\DevAssist`

---

## 系统要求

Windows 10 / 11（64 位）· 数据线 · 已开启 USB 调试的安卓手机 · 无额外依赖（ADB 已内置）
