## 能做什么

- 按厂商浏览常见预置 / 采集类组件（米加Ov华等）
- 一键扫描本机：已装 / 运行中 / 已停用
- **停用**（推荐）或 **卸载**（当前用户）
- 更新系统后可对照历史，提示组件是否被重新启用
- 本地操作日志可查；支持恢复所选组件

不往手机里安装常驻 App，只改当前用户下的组件状态。

---

## 使用前准备

1. 电脑：Windows 10 / 11  
2. 手机：用数据线连接电脑  
3. 打开 **开发人员选项**（设置 → 关于手机 → 连点版本号）  
4. 开启 **USB 调试**，手机上允许本机调试  

---

## 快速开始

1. 双击 `DevAssist.exe`  
2. **刷新设备** → **扫描本机**  
3. 勾选组件 → **按推荐停用**  
4. 需要时用 **恢复所选**

建议：**先停用 → 用几天 → 再考虑卸载**。

---

## 注意事项

- 新机 / 刚换卡：部分登记类组件可先保留  
- 优先「停用」；「卸载」更彻底但恢复稍麻烦  
- OTA 后组件可能被重新启用，再扫一次即可  
- 删除本软件：删掉 exe 即可；日志在 `%LOCALAPPDATA%\DevAssist`
